# OpenMW Verlet v1.3

This build keeps the v1.2 Verlet, Wiggle and Jiggle work and changes the advanced Jiggle quality-of-life UI:

- The Jiggle tab no longer expands an embedded setup panel.
- "Open Advanced Jiggle Setup..." toggles a separate Morrowind-themed window.
- The advanced window uses native MW_Window / MW_Button / MW_List / MW_TextEdit styling.
- It groups controls into three tabs:
  - Mesh Z Offsets
  - Mesh Blacklist
  - Player / NPC Rules
- Existing per-mesh offsets, blacklist editing, per-player/per-NPC toggles and named NPC Force ON/OFF rules are preserved.
- Closing the main settings screen also closes the advanced Jiggle setup window.

Build label: OpenMW-Verlet-v1.3
